# FPGA-Based Insulin Dosage Computation System

## Overview

This project presents an FPGA-based insulin dosage computation system for diabetes management. The system calculates insulin dosage based on patient parameters such as age, weight, current glucose level, previous glucose level, and previous insulin dosage.

The design was developed using Verilog HDL and implemented using Xilinx Vivado on a Nexys A7 FPGA board.

## Features

* Automated insulin dosage computation
* Verilog HDL implementation
* FSM-based control architecture
* Dual-Port RAM integration
* FPGA implementation on Nexys A7
* Hardware verification and simulation

## Hardware Used

* Nexys A7 FPGA Board
* Xilinx Artix-7 FPGA

## Software Used

* Verilog HDL
* Xilinx Vivado
* Vivado Simulator

## Project Modules

* PLL Module
* FSM Controller
* Insulin Computation Module
* Dual-Port RAM
* Top Integration Module

## Results

The system successfully computes insulin dosage and displays the output on the FPGA board. Simulation and hardware implementation results validated the design functionality.
